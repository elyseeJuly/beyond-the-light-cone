## 发布过程中的关键阻塞与修复

### 阻塞 1：PR #4 为 Draft 状态
- 现象：PR #4 无法直接合并
- 修复：`gh pr ready 4` 标记为 ready 后合并

### 阻塞 2：WebKit/mobile-safari E2E 坐标漂移
- 现象：教程步骤切换或屏幕旋转后，高亮框滞留旧坐标（如 click-earth 的地球框 110×110），导致"旋转后高亮框 X 漂移 300~524px"测试失败
- 根因：CI 上 WebKit/mobile-safari 在教程步骤切换后需要若干 rAF 帧，Tutorial 的 `updateRect` 循环才会将旧坐标更新为当前目标的坐标
- 修复：新增 `waitForHighlightAligned` 函数轮询直到高亮框中心与目标中心对齐（差值 < 4px），替换原先只等待稳定的 `waitForCoordsStable`

### 阻塞 3：Windows Tauri 构建 TS2339（核心阻塞）
- 现象：`DistributionChannel.scenario.test.ts` 第 62、68 行报 `error TS2339: Property 'packId'/'id' does not exist on type 'never'`，仅在 Windows MSVC 环境复现，本地 macOS tsc 通过
- 根因：`resolveJsonModule` 对 `asset_manifest.json` 中约 100 项的异构 `expansion.assets` 数组（各项 shape 不一致，部分有 `era` 字段部分无）在 Windows MSVC 下推断为 `never[]`，而 macOS 下推断为更宽松的联合类型
- 修复：将 `import manifestData from '../../../public/asset_manifest.json'` 改为 `import manifestDataRaw from '...'` + `const manifestData = manifestDataRaw as unknown as AssetManifest`，与 `AssetLoader` 运行时使用的类型保持一致。需经 `unknown` 中转是因为 JSON 中 `latestPatch: null` 与 `AssetManifest.latestPatch?: string` 不兼容
- 验证：本地 tsc 通过，DistributionChannel + AssetDownload 场景测试 15/15 通过
