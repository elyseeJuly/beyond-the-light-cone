# 游戏引导与教程系统重构调研报告 (Tutorial System Research & Audit)

本调研报告归档了对《光锥之外：纪元往事》现有教程体系的代码诊断，以及针对业界主流 4X 太空策略游戏（如《文明6》、《群星》、《无尽空间2》等）新手引导最佳实践的系统性分析。这些调研直接促成了「智脑顾问三层引导体系」的设计。

---

## 1. 现有教程体系代码诊断

当前游戏的代码中，新手引导功能分散在三个独立的组件中，存在明显的断裂感和信息过载问题。

### 1.1 `Tutorial.tsx` (当前的新手教程组件)
- **机制诊断**：当前教程是一个约 8 步的静态模态对话框。它虽然使用了遮罩和高亮，但完全是**纯文本阅读模式**。
- **核心缺陷**：
  - **缺乏实践**：玩家阅读了大量的背景设定，但从未真正在教程中进行过“点击建造”、“分配劳工”等改变游戏实质状态的操作。
  - **信息过载**：在游戏刚开始的 1 分钟内，把资源、科技、面壁者、战斗等概念一次性全部灌输给玩家。
  - **缺乏容错与反馈**：教程走完后直接消失，玩家正式接手游戏时往往处于“不知所措”的状态（例如不建采矿场导致资源枯竭）。

### 1.2 `BeginnerTasks.tsx` (新手任务清单)
- **机制诊断**：常驻右下角的 5 个 Checklist（完成第一项科技、任命部长、拥有采矿场、拥有加工厂、处理事件）。
- **核心缺陷**：
  - **与教程断裂**：任务没有前置策略说明，也没有对应的奖励机制。
  - **缺乏渐进性**：5 个任务固定不变，无法随着游戏进入「威慑纪元」或「广播纪元」提供更高级的战略指引。

### 1.3 `ContextualTips.tsx` (情境提示)
- **机制诊断**：监听 `ap-insufficient`、`turn-blocked` 等事件，通过 Toast 显示一条文字。
- **核心缺陷**：
  - **一次性设计**：通过 `localStorage` 标记，每条提示在玩家整个游戏生涯中**只会出现一次**。触发后若玩家忘记，再也没有复习途径。

## 2. 业界 4X 策略游戏教程最佳实践调研

针对上述问题，我们对业界同类项游戏进行了深入分析，总结出以下最佳实践模型：

### 2.1 《文明 6》 (Civilization VI) - 顾问系统 (Advisor System)
- **核心机制**：除了独立的教程战役，游戏中内置了持久的**顾问系统**。顾问分为军事、科技、文化、经济等类别。
- **借鉴价值**：
  - **渐进式揭示 (Progressive Disclosure)**：军事顾问只在发现蛮族或敌国时才会弹出提示，不会在第一回合就教你如何打仗。
  - **Contextual UI Badges**：在建造或科研面板，系统会给推荐的项目打上“顾问推荐”标记。

### 2.2 《群星》 (Stellaris) - VIR 助手与局势日志 (Situation Log)
- **核心机制**：通过名为 VIR 的虚拟助手进行引导，并将教程目标完全融入游戏的「局势日志」（任务系统）中。
- **借鉴价值**：
  - **任务导向学习 (Task-Oriented Learning)**：“建造一个采矿站”、“科研一项技术”被包装成了早期的主线任务。
  - **正向反馈机制**：完成这些教程任务会给予实际的游戏资源（矿石、能量币）奖励，极大强化了玩家探索的动力。
  - **分级教程强度**：玩家可以选择“完整教程”、“仅提示”或“完全关闭”。

### 2.3 《无尽空间 2》 (Endless Space 2) - UI 层级与特征门控
- **核心机制**：极其克制的主界面 UI，将复杂信息隐藏在二级和三级菜单中。
- **借鉴价值**：
  - **特征门控 (Feature Gating)**：在新手模式下，一些过于复杂的 DLC 机制（如黑客系统）会被暂时屏蔽或延后出现，确保玩家先掌握基础的 4X 循环（探索、扩张、开发、征服）。
  - **嵌套式 Tooltips**：基础 Tooltip 提供简要说明，按下特定键可展开更详尽的底层公式和维基说明。

### 2.4 《陷阵之志》 (Into the Breach) - 确定性设计与极简 UI
- **核心机制**：一款将信息透明度做到极致的回合制战棋。
- **借鉴价值**：
  - **Show, Don't Tell**：第一关故意设计成几乎不可能失败的谜题，让玩家通过观察敌人的攻击预警线，自己领悟“推拉”机制的妙用，而不是通过长篇大论来教学。

### 2.5 中国式策略游戏与《三体》语境的融合
- **叙事包装 (Diegetic Onboarding)**：教程不应该是一个突兀的“系统菜单”，而应该包装进世界观。在《三体》语境下，将教程包装为人类危机应对部门的**「智脑辅助系统开机校准」**，能极大增强沉浸感。
- **危机驱动动机**：在一开始就展示不可逆的危机（如三体舰队的 400 年倒计时），让玩家产生强烈的内在动机去学习“如何生存”。

## 3. 调研结论与改造方向指导

基于以上调研，本项目的教程改造必须摒弃“填鸭式静态弹窗”，转向以下三个方向：

1. **将操作指导融入叙事**：废弃纯粹的系统弹窗，引入“智脑”顾问身份。序章必须强制玩家实际操作一次资源分配和科研启动，而不是仅仅“告诉”他们怎么做。
2. **用任务奖励驱动学习**：把原有的静态 BeginnerTasks 改造成类似《群星》的任务日志系统。将中后期的系统（面壁者、执剑人、结局选择）拆分为对应纪元的推演目标。
3. **建立持久的帮助体系**：废弃一次性的 ContextualTips，建立一个可以随时查阅的顾问百科面板，并通过带有冷却时间的“警告弹幕”替代一次性提示。
