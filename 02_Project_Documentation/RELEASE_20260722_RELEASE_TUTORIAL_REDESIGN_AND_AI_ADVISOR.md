# Release / 智脑顾问与新手引导重构发布说明

> 日期：2026-07-22  
> 版本基线：v1.0.4 / Released  
> 发布状态：本地编译与门禁测试通过，核心机制与回归测试由 Vitest 全量验证

## 1. 发布目标

本次发布完成了游戏新手引导体系的重构，将原本突兀的静态弹窗升级为完全融入世界观的「最高执政官智脑辅助系统（智脑顾问）」。
同时，清理了前序版本遗留的跨周目缓存污染，并确保游戏内备受老玩家喜爱的「AI 智能托管」（自动代打）功能依然可用。

主要交付内容分为三个核心层级：
1. **第一层：开机校准（Tutorial）** - 9 步精细化交互序章，确保玩家掌握基本 4X 生产科研循环。
2. **第二层：纪元目标（MissionLog）** - 按危机纪元、威慑纪元、广播/掩体纪元渐进展示的战术任务链与点击奖赏。
3. **第三层：数据百科（AdvisorPanel）** - 包含产出公式、面壁执剑人机制及 6大胜利/4大失败结局路线图的常驻手册。

---

## 2. 玩家可见变化

### 主菜单与游戏界面

- **主菜单入口调整**：原有的“AI 智脑托管”初始开关被移除，替换为 `[ 🧠 智脑顾问 · 战术百科 ]` 按钮。玩家可在未进游戏前查阅百科知识。
- **游戏内双按钮**：游戏界面顶部 HUD 包含：
  - `[ 智脑顾问 ]` 图标：随时弹出百科面板。
  - `[ 智脑托管/手动 ]` 状态按钮：老玩家依然可以使用 AI 智能托管代打。

### 新手教程 (Tutorial)

- **交互性升级**：不再使用“填鸭式纯文本阅读”遮罩。玩家必须亲自点击地球、在轨道上建造一个采矿场、拖动滑块分配劳工、在科技树中启动“天文观测”科技。
- **防止卡死改进**：
  - 对没有操作目标的纯阅读步骤（如“监控三维产出”）或剧情展现步骤提供显式的 `[下一步]` 按钮。
  - 序章校准完成后展示 `[完成校准]` 绿色大按钮引导平滑过渡。
- **注入专属教学事件**：进行到第 8 步“应对突发危机”时，若当前回合没有任何随机事件，智脑会自动注入专属的“拦截 ETO 异常信号”事件供玩家练习决策。

### 局势推演目标 (MissionLog)

- 原本死板的 5 个静态任务清单升级为动态任务日志。任务会跟随游戏纪元的更替自动演进，提供相应的策略提示。
- 任务目标达成后不会静默完成，而是变为高亮且支持**手动点击领取奖励**（奖励会增加矿产、经济、AP上限等）。

### 智脑情境报警

- 废除了一次性情境提示。智脑现在会在“矿产连续 3 回合下降”、“稳定度低于 40%”、“威慑度降至 30% 以下”时，弹出标准化格式的 `[智脑警告]` 弹幕，并具备冷却时间（例如 5~8 回合 CD），不再重复骚扰玩家。

## 3. 技术交付与修复

- **多周目缓存污染修复**：统一将周目敏感的本地缓存（已领奖任务、提示触发记录、冷却时间记录等）加上 `session:` 前缀。在主菜单点击开始任何新游戏时，自动正则过滤并清除 `session:` 开头的全部缓存。
- **Tauri Rust 后端版本同步**：将 `src-tauri/Cargo.toml` 与 `Cargo.lock` 中的 rust 后端包版本由旧版 `1.0.2` 同步升级至最新的 `1.0.4`。
- **修复 `build-stope` 判定死锁**：在步骤 3 玩家点击建造采矿场后自动判定通过，与提示文案保持一致。
- **控制台防御性报错**：在教程状态机判定逻辑中加入了 `default` 分支报错，任何新增但未声明判定规则的步骤都会直接抛出 `console.error`，防止未来静默死锁。
