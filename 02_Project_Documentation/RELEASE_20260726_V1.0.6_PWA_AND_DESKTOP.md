## 本次修复

1. 教程“选中地球”热点改为可聚焦、可键盘操作且明确启用指针事件的按钮，真实浏览器点击不再穿透到星图。
2. 封面在短横屏视口使用紧凑布局，标题说明与页脚让位，开始游戏和新教程入口保持可见、可点击。
3. 教程 E2E 使用真实鼠标/键盘交互：欢迎页手动启程、地球选择和劳力滑块提交均验证实际游戏状态。
4. PWA 缓存名改为从 `package.json` 动态生成，避免版本升级后继续复用旧缓存标识。
5. 稳定 Release 增加完整产物门禁；Web ZIP、Windows MSI/EXE、macOS DMG 任一缺失时不发布。
