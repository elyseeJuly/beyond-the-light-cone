## 本次变更

1. **`App.tsx` 布局判定**
   - 从 `showDesktopLayout = !isMobile || isMobileLandscape`
   - 改为 `showDesktopLayout = !isMobile && !isMobileLandscape`
   - 移动端横屏不再走桌面三栏布局

2. **`helpers.ts` 断点对齐**
   - 修复 `switchView` 中断点 640px 与 `useBreakpoint` 768px 不一致的问题
   - `waitForMainUI` 增加 touch + landscape 判定，与 `useBreakpoint` 对齐

---

## 本次移除

- **`.mobile-landscape-scale` 缩放方案**
  - 删除 `index.css` 中 `transform: scale(0.85) + width: 117.64%` 的实现
  - 该方案导致 844×390 视口下 TopHUD 右侧溢出约 74.41px
