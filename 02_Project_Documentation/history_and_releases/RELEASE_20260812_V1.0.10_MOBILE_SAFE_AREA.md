## 本次修复

1. **全局安全区偏移适配**
   - 移除全局 `body` 的 `safe-area` padding
   - 在 `TopHUD`、`MobileBottomNav`、`MobileLandscapeHub`、`.drawer-panel` 中实现精细化安全区及内边距动态计算
   - 彻底解决刘海屏下底部导航和右侧面板被强行裁剪的问题

2. **低高度视口模态框适配**
   - 对 `StoryModal`、`SettingsModal`、`FleetModal`、`BattleScreen` 等所有核心模态窗口添加 `max-h-[90vh]` 高度约束及内部自适应滚动

3. **StoryModal 横屏精简布局**
   - 低高度横屏视口下自动隐藏大肖像，收缩内边距并优化字体
   - 保证剧情文本和决策按钮 100% 可见

4. **SettingsModal 窄屏布局重构**
   - 移动端自动切换为顶部水平滚动 Tab 栏 + 下方流式设置项的垂直布局

5. **FleetModal 响应式流式布局**
   - 窄屏下自动将舰队信息项切换为垂直排版，防止派遣按钮和选择器溢出截断

6. **详情抽屉边缘呼出按钮**
   - 针对非星图页面关闭 Inspector 后无法拉起的交互死路，引入半透明"详情 ◀"边缘胶囊按钮，允许随时重新呼出抽屉

7. **React Stale Closure 闭包卡死修复**
   - 修复 `App.tsx` 中 window 事件监听器挂载时对 `showDesktopLayout` 的 stale closure 引用
   - 保证视口切换时抽屉开合控制逻辑的最新有效

8. **E2E 测试健壮性及可靠性提升**
   - 修复 `startFreeExplore` 对 PWA 资源下载授权模态框遮罩的自动检测与关闭
   - 模拟物理点击前引入 Earth 视角聚焦步骤
   - 坐标命中测试改为浏览器 native `MouseEvent` 精确派发
   - `tutorial-guided` 滑块拖动改为键盘 Focus + `ArrowRight` 微调
